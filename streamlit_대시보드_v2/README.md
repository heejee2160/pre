# 부산 상권 위험 조기진단 대시보드 — Streamlit (Figma S-00 · 2페이지 구성 반영)

## 실행
```
pip install -r requirements.txt
streamlit run app.py
```
DB 없이 data/ 폴더의 CSV만 읽습니다. 화면 상태는 주소창 `?page=&dong=&month=&gu=&ind=` 에 남아서
새로고침·링크 공유를 해도 같은 화면이 열립니다.

## 화면
### 상단 배너
로고 · 제목 · 단계 버튼(1 전체 / 2 행정동·업종 상세 / 3 근거 확인 및 자료 다운) · 참고자료 배지 · 데이터 기준 줄

### ① 전체 지도 (S-00)
- 왼쪽: 아이콘 레일 / 조건 선택(기준월·구·군·판단 보류 표시) / 카드업종 11개 버튼 / 상세조건(최소 점포 수·폐업률 범위) / 위험순위 TOP 5(클릭 → ②)
- 지도(components/busan_map):
  - 처음엔 ‘폐업예측 한 눈에 보기’ 팝업. 다른 순위에 마우스를 올리면 펼쳐지며 단계·부산 평균 대비·위험 신호 표시, ‘상세 분석 →’ → ②
  - 팝업을 닫으면 행정동에 마우스를 올릴 때 **오른쪽 아래 카드**에 그 동 정보(선 없음, 위치 핀) · 클릭 → ②
  - **‘한 번에 비교하기’** 버튼 → 지도 위 비교 패널: ‘행정동 선택’으로 최대 4곳 추가, 칩 ✕로 빼기, 지표 표 + 차이
  - 검색창(행정동 이름), 행정동/상권 토글(상권은 준비 중), 확대·축소·처음 위치·전체 화면, 마우스 휠 확대·드래그 이동
  - 왼쪽 ‘팝업으로 크게 보기’ 버튼으로 팝업 다시 열기

### ② 행정동·업종 상세 (스크롤)
제목·단계·요약 → [폐업위험률 큰 카드 | 예상 폐업 점포·위험 순위 | 재단 보증현황(실측)] → 상권 실측 신호
→ [업종별 폐업위험 | 폐업위험을 높이는 원인(도넛) | 언제부터 나빠졌나] → [주변 행정동 위험단계 지도 | 주변과 비교 · 예측 신뢰도 · 점포 순증]
- 왼쪽 패널: 선택한 행정동·기준월 바꾸기, 비교 대상(부산·구 평균, 직접 추가 1곳), 업종 고르기, ‘선택 업종 담고 근거 보기 →’(③)
- 주변 지도에서 다른 동을 클릭하면 그 동으로 이동 (Streamlit 1.35+)

### ③ 근거 확인 및 자료 다운
- 탭1: 현장 확인 질문 체크 · 메모 · 근거 리포트(.md) · 이 동 월별 지표(.csv)
- 탭2: 원자료 7종 미리보기·CSV, 구·군·기간 필터, 전체 zip
